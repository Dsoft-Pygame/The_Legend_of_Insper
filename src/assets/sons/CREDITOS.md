# Créditos dos sons

Todos os sons desta pasta foram gerados por código (síntese de ondas quadrada, triangular, serra, seno e ruído) pelo Claude, o assistente de IA da Anthropic, a pedido do grupo. Nenhum arquivo veio de terceiros, então não há licença externa a seguir.

## Efeitos (`.wav`)

| Arquivo | Som | Origem |
|---|---|---|
| `ataque.wav` | golpe: "fuuu" de ruído descendo com estalo agudo | gerado pelo Claude |
| `acerto.wav` | pancada grave e curta | gerado pelo Claude |
| `inimigo_derrotado.wav` | arpejo descendo e um "puf" | gerado pelo Claude |
| `chefe_derrotado.wav` | explosão longa e fanfarra de vitória | gerado pelo Claude |
| `heroi_derrotado.wav` | notas tristes descendo | gerado pelo Claude |
| `porta.wav` | subida rápida, como teletransporte | gerado pelo Claude |
| `menu_mover.wav` | bip curtinho | gerado pelo Claude |
| `menu_confirmar.wav` | dois bips subindo | gerado pelo Claude |
| `especial_pronto.wav` | "plim" de três notas subindo, quando o especial recarrega | gerado pelo Claude |
